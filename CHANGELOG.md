# Изменения

## v0.1.2

- Добавлено сканирование QR-кода подписки на Android: на странице "Профили" кнопка "Добавить" теперь спрашивает способ — QR-код или ссылка/ключ.
- Исправлен баг в проверке конфигурации Mihomo: при пустом выводе ядра в баннере ошибки показывался буквальный текст `\n` вместо причины; теперь показывается понятное сообщение (чаще всего — антивирус блокирует неподписанный mihomo.exe).

## v0.1.1

- Исправлена сборка конфигурации SNI Spoofing: больше не добавляются неподдерживаемые глобальные параметры Mihomo.
- SNI применяется только к совместимым типам прокси; исходное имя сервера Reality сохраняется.
- Добавлены регрессионные тесты для SNI-конфигурации.
- HyL не объявляется поддерживаемым транспортом Brew до реализации рабочего QUIC/VPN data plane в отдельном проекте.
