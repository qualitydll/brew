# Изменения

## v0.1.1

- Исправлена сборка конфигурации SNI Spoofing: больше не добавляются неподдерживаемые глобальные параметры Mihomo.
- SNI применяется только к совместимым типам прокси; исходное имя сервера Reality сохраняется.
- Добавлены регрессионные тесты для SNI-конфигурации.
- HyL не объявляется поддерживаемым транспортом Brew до реализации рабочего QUIC/VPN data plane в отдельном проекте.
